# kenchiku-kokuji

建築関係の**告示**を、国土交通省の一次情報源から収集し、機械可読な台帳と
本文テキストのコーパスとして整えるパイプライン。

告示には法令のような統一データベースが無く（デジタル庁も公式に認めている）、
現行文は商業出版・有料DBの編集成果の中にしか存在しない。本プロジェクトは
その代替ではなく、**一次情報源から辿れる材料を集める**ことを目的とする。
溶け込み（改正を適用した現行文の生成）や現行性の判定は行わない。
各レコードに出典URLと文書番号を保持し、原本で検証できる形にする。

## 収集源（いずれも一次情報）

| 情報源 | 内容 | 備考 |
|---|---|---|
| 告示・通達一覧（Excel） | https://www.mlit.go.jp/notice/ で配布 | 全省庁分を含む。住宅局分は2019年で更新停止（実測） |
| 住宅局「建築基準法等に基づく告示の制定・改正について」 | 制定・改正の告知ページ | 2020年以降分は実質ここにしか出ない |
| 官報（インターネット版） | 国立印刷局 https://www.kanpo.go.jp/ の目次＋本文PDF | 直近90日分が無料公開。チェック済み日付を `data/kanpo_state.json` に持ち、未チェック分だけを処理する。90日より短い間隔で回し続ければ「今日から未来」の分は無料のまま蓄積できる。国土交通省以外の発出者（総務省＝消防法関係など）も拾える唯一の源 |

対象ドメインの定義は `config/domain.json` に明示している
（建築法規クラスタの法令名〈旧法名含む〉＋住宅局所管）。

## 出力

- `data/notices.jsonl` — 告示1件＝1行の台帳。IDは `発出者-西暦年-番号`
  （例: `mlit-2026-1316`、`kensetsu-2000-1399`）。表記揺れ
  （千二十四／一〇二四／１０２４）は正規化して同一性を判定する
- `data/texts/<id>.txt` — 本文テキスト（PDFから抽出）
- `data/stats.md` — 収集統計と、本文が取得できなかったレコードの一覧

## 使い方

```bash
pip install -r requirements.txt
PYTHONPATH=src python -m kenchiku_kokuji.run_all
python -m unittest discover tests
```

再実行すると、取得済みの本文は再取得しない（台帳が再開ポイントになる）。
`--force` で全件再取得。

## 設計判断と限界

詳しくは `docs/DESIGN.md`。要点:

- 完全な母集団は官報のみ。本パイプラインの網羅は3つの情報源の和集合までで、
  昭和期など古い告示は薄い。ただし官報分は運用開始日（2026-11-11）以降、
  未来方向には窓を空けずに蓄積されていく
- 改正告示は独立したレコードとして収集する（原文＋改正を並べる方式）。
  「どの告示がどれを改正したか」の関係抽出は未実施
- 図表中心の告示はテキスト抽出の品質が落ちる。文字数が台帳に記録されるので、
  薄いレコードは原本PDFで確認すること

## ライセンスと出典

- コード: MIT License（`LICENSE`）
- 告示の本文: 法令・告示の原文は著作権法第13条により著作権の対象外。
  本コーパスは一次情報源から自ら収集・再構成したもので、
  商業DB等の編集成果物は一切含まない
- 出典:
  - 国土交通省「告示・通達一覧」 https://www.mlit.go.jp/notice/
  - 国土交通省住宅局「建築基準法等に基づく告示の制定・改正について」
    https://www.mlit.go.jp/jutakukentiku/build/jutakukentiku_house_tk_000096.html
  - 官報発行サイト（内閣府） https://www.kanpo.go.jp/
    （官報のコンテンツは公共データ利用規約（第1.0版）に基づき出典を記載して利用）
  - 各レコードには出典URL（`sources` / `document_url`）を保持しており、
    原本で検証できる
- 取得は各サイトの負荷に配慮し、間隔を空けて行う（`build.py` の `DELAY_SEC`）

## 収集について

本プロジェクトの収集パイプラインの構築とデータの整備は、Metaのパーソナル
AIエージェント「Muse」の支援を受けて行われた。収集は週次で自動実行され、
新規に公布された建築関係告示が台帳へ追加されていく。

現在の収録状況（2026-11-11時点）: 479件（うち本文テキストあり441件・
約379万字）。詳細は `data/stats.md` を参照。
